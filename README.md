# Песенник — поём вместе

Приложение для совместного пения: список песен, крупный текст, плавная автопрокрутка, пауза касанием и чтение без интернета. Работает на GitHub Pages без серверной базы данных, токенов и платных внешних сервисов. Песни редактируются прямо в GitHub.

## Как изменить песню

1. Откройте папку **songs** в этом репозитории.
2. Откройте нужный `.txt` файл и нажмите значок карандаша **Edit this file**.
3. Первая строка — название песни. После неё — текст. Куплеты разделяйте пустой строкой, припев повторяйте в нужных местах.
4. Нажмите **Commit changes**, затем подтвердите сохранение в ветку **main**.
5. Дождитесь зелёной отметки публикации во вкладке **Actions**.
6. В приложении на телефоне нажмите **Обновить сборник** с включённым интернетом.

Тексты доступны всем посетителям опубликованного сайта. Менять исходные файлы могут только пользователи с правом записи в репозиторий.

## Как добавить песню

В папке **songs** выберите **Add file → Create new file**. Укажите новое имя, например `song-004.txt`, и заполните файл:

```text
Название песни

Первая строка куплета,
Вторая строка куплета.

Припев
Текст припева.
```

Сохраните через **Commit changes**. Список песен соберётся автоматически, отдельный индекс править не нужно. Поддерживаются имена файлов на русском языке. Имена файлов должны быть уникальными. Сохраняйте имя файла при изменении названия песни — так не потеряется выбранная для неё скорость.

Для удаления песни удалите её `.txt` файл через GitHub и сохраните изменение. После публикации и обновления сборника на телефоне песня исчезнет. Старые тексты и удалённые файлы доступны через историю GitHub.

Полностью пустые файлы временно пропускаются и не мешают публикации остальных песен. Когда вы заполните такой файл, песня автоматически попадёт в следующую публикацию. Если в непустом файле отсутствует название или текст, публикация завершится ошибкой; предыдущая рабочая версия останется доступной. Подробнее об ошибке — во вкладке **Actions**. Исправьте файл и сохраните снова.

## Как пользоваться на Android

Откройте сайт в Chrome с интернетом и дождитесь «Готово к работе без интернета». В меню Chrome выберите «Добавить на главный экран» или «Установить приложение».

Песня прокручивается через две секунды после открытия. Короткое касание — пауза или продолжение. Текст можно двигать пальцем; после жеста сохраняется прежнее состояние прокрутки. Скорость и размер текста регулируются кнопками. После сворачивания прокрутка остаётся на паузе до касания. На странице песни запрашивается удержание экрана включённым; при отказе системы появляется сообщение.

После первой загрузки песни используются с телефона. Новые тексты скачиваются только кнопкой **Обновить сборник**, не при каждом запуске. Обновление кода PWA браузером выполняется отдельно. Если связи нет, прежний сборник остаётся доступным. После очистки данных сайта потребуется первая загрузка заново.

При переходе со старого адреса приложения откройте новый адрес с интернетом и установите его значок заново: сохранённые данные и настройки между разными сайтами не переносятся автоматически.

## Первая публикация на GitHub Pages

1. Создайте публичный репозиторий (например, `pesennik`) в вашем аккаунте.
2. Загрузите исходные файлы этого проекта с сохранением папок, включая `.github/workflows/pages.yml`, и сохраните их в ветке `main`.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Если первая сборка началась до включения Pages и завершилась ошибкой, откройте **Actions → Публикация Песенника → Run workflow** и запустите её для `main`.
5. После успешной публикации ссылка находится в **Settings → Pages** и в результате Actions. Обычно это `https://ВАШ-АККАУНТ.github.io/pesennik/`.

После любого изменения в `main` GitHub проверит тексты, соберёт `dist/catalog.json` и опубликует сайт. В приложении используется единый снимок сборника: при сбое или обрыве загрузки старые песни не заменяются частично.

## Локальная разработка

Требуется Node.js 22 или новее. Зависимостей нет, `npm install` не нужен.

```sh
node --test
node scripts/build.mjs
node scripts/serve.mjs
```

Предпросмотр: `http://127.0.0.1:8080/pesennik/`. Вложенный путь специально совпадает с устройством GitHub Pages. Изменения в `web/` и `songs/` применяются после повторной сборки. Для изменения кода оболочки очистите данные локального сайта или закройте все его вкладки, чтобы новая версия Service Worker активировалась. Открытая песня никогда не перезагружается автоматически.

В папке `songs/` — исходные тексты, в `web/` — интерфейс, в `scripts/` — сборка и локальный сервер, в `tests/` — проверки формата, атомарного обновления и автономного кэша. Готовый `dist/` генерируется и не хранится в репозитории. Серверные файлы и секреты старой версии Sites в этот проект не входят.
